# 🏨 RR Resort Power BI Dashboard

> **Interactive Business Intelligence dashboard for analysing resort operations, guest activity, restaurant performance, inventory, staff performance, and financial metrics using Microsoft Power BI.**

---

## 📌 Project Overview

The **RR Resort Power BI Dashboard** is a Business Intelligence and Data Visualization project developed using **Microsoft Power BI**.

The dashboard brings together multiple areas of resort operations into an interactive reporting solution, helping users explore operational, customer, inventory, staff, and financial information through dedicated dashboard pages.

The project focuses on transforming structured resort data into **interactive KPIs, visual reports, and business-focused insights**.

---

## 🎯 Business Objective

The objective of this project is to provide a centralized dashboard for monitoring key areas of resort performance and supporting data-driven decision-making.

The dashboard is designed to help answer questions such as:

* How is overall resort performance?
* How are guest-related metrics changing?
* How are restaurant and kitchen operations performing?
* What is the current inventory position?
* How is staff performance and cost being represented?
* How are financial and revenue metrics performing?
* Which operational areas require further investigation?

The dashboard contains **six interactive reporting pages**:

Provides an overall view of the resort's business and operational performance.

### 3. Restaurant & Kitchen Dashboard

Analyses restaurant and kitchen operations.

* Restaurant performance indicators

### 4. Inventory Management Dashboard

Provides visibility into inventory and stock-related information.

### 5. Staff Performance Dashboard

Provides insights into staff-related information and performance.

### 6. Finance & Revenue Dashboard

Focuses on financial and revenue-related performance.

* Revenue

## 📈 Key KPIs

The project includes business-focused KPIs such as:

* **Total Revenue**
* **Total Bookings**
* **Occupancy Rate**
* **Total Guests**
* **Restaurant Orders**
* **Inventory Value**
* **Salary Cost**
* **Average Guest Rating**

These KPIs are used across the dashboard to provide a consolidated view of operational and financial performance.
