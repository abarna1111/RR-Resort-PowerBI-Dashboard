# RR Resort Power BI Dashboard

## 📖 Overview

RR Resort Power BI Dashboard is a Business Intelligence and Data Visualization project developed using Microsoft Power BI.

The dashboard provides interactive insights into different areas of RR Resort operations, including executive performance, guest analytics, restaurant and kitchen operations, inventory management, staff performance, and finance & revenue analysis.

The project presents resort-related data through multiple interactive dashboard pages, allowing users to explore business and operational information in a clear and visual format.
